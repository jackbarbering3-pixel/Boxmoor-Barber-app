# Boxmoor Barbers App

A mobile-first Expo/React Native MVP for Boxmoor Barbers.

## Included
- Premium dark-green Boxmoor visual style
- Booking flow for 2–3 barbers
- Clean service list with no haircut photography
- Membership dashboard with monthly haircut allowance
- Customer account screen
- Demo appointment confirmation

## Run
1. Install Node.js.
2. Run `npm install`.
3. Run `npm start`.
4. Open with Expo Go or an iOS/Android simulator.

This starter uses local demo data. The next production phase should connect real booking availability, authentication, database storage and subscription/direct-debit payments.
